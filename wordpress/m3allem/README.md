# المعلّم — تيم ديال WordPress

منصة كتجمع المعلّم بالكليان. باب منقوش كيتحل بضغطة على القفل، جولة على زونات الحرف، وجوج واجهات: وحدة للكليان ووحدة للمعلّم. كلشي بالدارجة و RTL.

الداتا كاملة كتجي من WordPress — ماكاين حتى شي حاجة مكتوبة فالكود.

---

## التركيب

1. دير zip للفولدر `m3allem` (ولا حطّو نيشان فـ `wp-content/themes/`).
2. **Appearance → Themes → Add New → Upload Theme** وفعّلو.
3. غير ما تفعّلو، غادي يتصاوبو أوتوماتيكيا:
   - 9 حرف فالتاكسونومي **الحرف**
   - رول جديد اسمو **معلّم**
4. صاوب جوج صفحات بهاد السلوگ بالضبط:

   | العنوان | السلوگ |
   |---|---|
   | الواجهة ديال الكليان | `client` |
   | الواجهة ديال المعلّم | `pro` |

   التيم كيلقاهم بوحدو (`page-client.php` و `page-pro.php`) — ماتزيدش شي تامبليت.
5. **Settings → Permalinks → Save** (باش تتحدّث الروابط).

---

## التصاور

**Appearance → Customize → الباب ديال الدخول**

- **التصويرة ديال الباب** — خاصها تكون مصوّرة من قدّام، موازية، والقفل فالوسط. كتّقسم على جوج دفوف من الوسط.
- **التصويرة ديال الداخل** — لي كتبان من بعد ما يتحل الباب.
- **بلاصة القفل** — رقم من 0 حتى 1. إلا الدائرة ماجاتش على القفل، بدّل هاد الرقم شوية (الافتراضي `0.655`).

كل زون ديال حرفة عندو التصويرة ديالو: **الحرف → بدّل الحرفة → ID ديال الصورة** (تالع الصورة فالمكتبة وخود الـID).

> إلا مابدّلتيش تصاور الباب والداخل، التيم كيستعمل تصاور البداية مستضافة برّا. **الأحسن تالع تصاورك** باش الموقع يبقى مستقل.

## كيفاش تزيد معلّم

**من الأدمين:** المعلّمية → زيد معلّم جديد. عمّر السمية، الحرفة، التيليفون، المدينة، وشيّك «موثّق» إلا صيفط الكارط.

**المعلّم كيسجّل راسو:** كيمشي لـ `/pro/`، كيعمّر الفورم، وكيتصاوب ليه حساب + بروفايل **فانتظار التشييك**. كتشوفو فـ المعلّمية → Pending وكتنشرو من بعد ما تتأكد.

**الصور ديال الخدمة (بحال انسطا):** حيّد الصور فالبروفايل ديال المعلّم (Media → Uploaded to this post). كيبانو فالبروفايل وفالداشبورد.

## التقييمات

كل تقييم هو تعليق عادي ديال WordPress + نقطة من 1 حتى 5. المعدل وعدد التقييمات كيتحسبو أوتوماتيكيا كل مرة يتقبل ولا يتحيّد شي تعليق.

باش تخلي التقييمات ماتبانش حتى تشيّكها: **Settings → Discussion → Comment must be manually approved**.

## المشاكل العاجلة

الكليان كينشر المشكل من `/client/`. كيتسجّل فـ **المشاكل العاجلة** فالأدمين، وكيبان للمعلّمية فالداشبورد ديالهم بزر ديال المكالمة نيشان.

## على Hostinger (Business)

1. **hPanel → Websites → Auto Installer → WordPress**.
2. **hPanel → Security → SSL** — فعّل الشهادة المجانية وشغّل **Force HTTPS**.
   ضروري: بلا HTTPS الأبليكاسيون (PWA) مايخدمش.
3. **hPanel → Advanced → PHP Configuration** — خلي PHP 8.1 ولا فوق.
4. رفع التيم من **Appearance → Themes → Upload Theme**.
5. صاوب صفحتين `client` و `pro`، ومن بعد **Settings → Permalinks → Save**.

## أبليكاسيون أندرويد (APK)

التيم كيصاوب **PWA** كاملة أوتوماتيكيا: `manifest`، service worker، وصفحة تبان فاش تقطع الأنترنيت. يعني **ماخاصكش تعاود تكتب الأبليكاسيون** — كتلف الموقع فـAPK.

**قبل كلشي:** الموقع خاصو يكون على HTTPS وخدّام.

### الطريقة (10 دقائق)

1. سير لـ **pwabuilder.com** ودخّل اللينك ديال الموقع.
2. كيعطيك نقطة. ضغط **Package for stores → Android**.
3. حمّل الزيب. فيه:
   - `.aab` — لي كتصيفط لـGoogle Play
   - `.apk` — لي كتجرّب بيه فالتيليفون نيشان
   - `assetlinks.json`
4. **مهم بزاف:** الملف `assetlinks.json` خاصو يمشي فـ:
   ```
   public_html/.well-known/assetlinks.json
   ```
   من **hPanel → File Manager**. صاوب فولدر `.well-known` إلا ماكانش.
   تأكد أنه كيتحل من `https://SITE/.well-known/assetlinks.json`.

   بلا هاد الملف، الأبليكاسيون غادي يبان فيه **بار ديال النافيغاتور فوق**. بيه كيولّي بحال أبليكاسيون حقيقي.
5. جرّب الـ`.apk` فتيليفون أندرويد.
6. باش تحطو فـGoogle Play: حساب Play Console (**25$ مرة وحدة**) وصيفط الـ`.aab`.

### الأيقونة والسمية
**Appearance → Customize → الأبليكاسيون (PWA)** — بدّل السمية القصيرة والأيقونة.
الأيقونة خاصها **512×512 على الأقل** والرسم فالوسط، حيت أندرويد كيقص الأطراف.

### الأنترنيت
الصفحات كتّجيب **من الشبكة الأول** باش أي معلّم جديد يبان دغيا؛ إلا ماكانش الأنترنيت كتّخدم النسخة المحفوظة، وإلا حتى هي ماكايناش كتبان صفحة «ماكاينش الأنترنيت».

## المتطلبات

WordPress 6.0+ و PHP 7.4+. ماكيحتاج حتى پلوگين.

## حوايج ماكايناش

- الدخول بالتيليفون + كود SMS — WordPress كيدخّل بالإيميل. إلا بغيتي OTP خاصك پلوگين.
- الخريطة والمسافة بالكيلومتر — كاينين الحقول `_m3_lat` و `_m3_lng` ومعمّرين، ولكن مازال ماتربطوش بشي خريطة.
